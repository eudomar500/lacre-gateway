Drop a signed email and GenLayer validators fetch the sender's keys and check the signature by consensus.

    
Once that is final, the body is served and its fields are read, agreed on the same way.

    
Only then is it recorded.

  






  
PRIMITIVES

  

    

      
01

      
Router

      
Resolves each role to its current contract, so a new version needs no client change.

      
—

    

    

      
02

      
Key cache

      
Holds the sender keys the validators agreed on, with a quarantine for a domain seen the first time.

      
—

    

    

      
03

      
Verifier

      
Checks a signed email against the cached key and records whether it is valid and aligned.

      
—

    

    

      
04

      
Extractor (patterns)

      
Reads the fields of a message with patterns agreed per sender domain.

      
—

    

    

      
05

      
Extractor (LLM)

      
Reads the fields of a message with a model, accepted only when the validators read it alike.

WHY GENLAYER

  

    

      
01

      
      
Keys obtained
by consensus

      
Validators each fetch the sender's signing key and must agree on it, so no single resolver decides.

    

    

      
02

      
      
New senders
as data

      
An unknown domain needs no integration: its key is fetched and recorded the first time it signs.

    

    

      
03

      
      
Interpretation
by consensus

      
What the email says is accepted only when independent validators read it the same way.
